# BRCA1_NP_009225.1
This repository contains a 100 ns atomistic MD simulation of the BRCA1 (breast cancer type 1 susceptibility protein isoform 1). For this the Variant ID NP_009225.1 was retrieved from NIH and the structure predicted using AlphaFold3. The system was created using CHARMM-GUI. For the simulations the MPCDF HPC was utilized.

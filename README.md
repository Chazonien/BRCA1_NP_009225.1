# BRCA1_NP_009225.1
This repository contains a .zip file of a 100 ns atomistic MD simulation of BRCA1 (breast cancer type 1 susceptibility protein isoform 1). We retrieved Variant ID NP_009225.1 from NIH, and predicted the structure using AlphaFold3. The system was created using CHARMM-GUI. We used the MPCDF HPC for the simulations.
